WORKOUT RESET — INSTALL

1. Create a new GitHub repository, for example: workout-reset
2. Upload:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
   apple-touch-icon.png
3. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the published HTTPS URL on the phone.
5. iPhone/iPad: Safari > Share > Add to Home Screen.
   Android: Chrome > menu > Install app / Add to Home screen.

Each person's preferences, weight entries, checkmarks, and completion count are stored locally on that person's device/browser.

Current app features:
- Four workout days per week
- 3-week rotation
- Strength, full body, Yoga, and Pilates days
- 30-minute timer
- 10-minute "Not Today" option
- Low-impact setting
- Difficulty selector
- Optional weight tracker
- Custom equipment
- Exercise form pop-ups and swap buttons

UPDATE: Replace the six existing app files in the SAME GitHub Pages repository. Work Mode is saved locally and stays enabled until switched off. Original checkmarks, weights and settings are retained on the same origin. Work Mode uses separate daily checkmarks and shares the completed-workout total. Choose any of the four numbered Work Mode workouts on any day. Work Mode uses dumbbells and bodyweight only, with no jumping, yoga or Pilates. The original routine is unchanged. Reopen the app after deployment; iOS may require re-adding the home screen shortcut to refresh its icon.
